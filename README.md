# PEEPEE — Portfolio

เว็บพอร์ตโฟลิโอ "Fail fast. Learn fast." เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

```
peepee-portfolio/
├── index.html      ← เนื้อหาทั้งหมดของเว็บ (แก้ข้อความตรงนี้)
├── css/style.css   ← สี ฟอนต์ เลย์เอาต์
├── js/main.js      ← โมชั่น (Story, ก้อนสี่เหลี่ยมชนขอบเว็บ ฯลฯ)
└── assets/         ← ใส่รูปภาพที่นี่
```

## ดูบนเครื่องตัวเอง
ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย
หรือถ้ามี VS Code ให้ใช้ส่วนเสริม **Live Server** แล้วกด "Go Live"

## แก้เนื้อหา
เปิด `index.html` แล้วหาคอมเมนต์ `<!-- ... -->` ในแต่ละส่วน

- **รูปภาพ**: เอารูปใส่โฟลเดอร์ `assets/` แล้วเปลี่ยน
  `<div class="ph" data-label="..."></div>` เป็น
  `<img class="ph" src="assets/ชื่อรูป.jpg" alt="คำอธิบายรูป" style="object-fit:cover">`
  - รูปผลงาน: อัตราส่วน 3:2 (เช่น 1200×800)
  - รูปตัวเอง: 4:5 (เช่น 800×1000)
- **ผลงาน**: คัดลอก `<article class="card rise"> … </article>` เพื่อเพิ่มชิ้นใหม่
- **อีเมล / โซเชียล**: อยู่ในส่วน `05 CONTACT` (เปลี่ยนทั้ง `href` และข้อความ)
- **สีฟ้า**: เปลี่ยนค่า `--blue` ใน `css/style.css`

## เอาขึ้นออนไลน์ด้วย Vercel (ฟรี)
1. สร้างบัญชี [GitHub](https://github.com) แล้วสร้าง repository ใหม่ เช่น `peepee-portfolio`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (ลากวางในหน้าเว็บ GitHub ได้เลย → "Add file" → "Upload files")
3. เข้า [vercel.com](https://vercel.com) → Sign up ด้วย GitHub
4. กด **Add New… → Project** → เลือก repository `peepee-portfolio` → **Deploy**
   (Framework Preset เลือก "Other" ไม่ต้องตั้งค่าอะไรเพิ่ม)
5. ได้ลิงก์เว็บ เช่น `peepee-portfolio.vercel.app`
   ครั้งต่อไปแค่แก้ไฟล์ใน GitHub เว็บจะอัปเดตเองอัตโนมัติ

## โมชั่นที่มีในเว็บ
- **Home**: ตัว P-E-E ลอยขึ้นทีละตัว แล้วก้อนสี่เหลี่ยมพุ่งทะลุขอบจอขวา กลิ้งเข้ามาเป็นจุดท้ายคำ
- **Story**: แต่ละประโยคค่อย ๆ ชัดขึ้นตอนเลื่อนมากลางจอ และเบลอออกเมื่อเลื่อนผ่าน
- **About / Contact**: กล่องสีขาวขยายขึ้นมาเมื่อเลื่อนถึง
- **Work**: ก้อนสี่เหลี่ยมพุ่งชนขอบเว็บจนทะลุ แล้วการ์ดผลงานลอยขึ้นทีละใบ (กด "Replay impact" เพื่อดูอีกรอบ)
- ถ้าผู้ใช้เปิดโหมดลดการเคลื่อนไหว (Reduce motion) ในเครื่อง เว็บจะปิดโมชั่นให้เอง
